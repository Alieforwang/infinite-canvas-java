# 产品范围契约（Phase 0）

> 本文是 PRD / 技术方案的唯一范围基线。PRD 与技术方案中的功能、页面、计费规则必须与本文一致；如需变更，先改本文。
> 状态：待用户确认（M0 阶段）。
> 最后更新：2026-11-03

## 1. 产品定位

**无限画布 · 视频生成平台**：面向 AI 视频创作的一站式工作台。

- 用户在「视频创作台」用表单快速出片，或在「无限画布」上把提示词、参考图、生成节点连线编排，按依赖关系连续生成视频。
- 平台管理员在管理后台配置「OpenAI 兼容协议」的模型渠道（Base URL / API Key / 模型 / 价格），所有用户共用，API Key 不出服务器。
- 平台负责账号、模型接入、异步任务队列、积分/套餐计费、文件存储、资产管理。
- 参考项目 `D:\software\desk\infinite-canvas` 的前端（Vite + React 19 + AntD 6 + Zustand + localforage）作为用户端 UI 基础，裁剪后复用；交互与视觉风格保持一致。

## 2. 角色

| 角色 | 说明 | 能力 |
|---|---|---|
| 访客 | 未登录 | 注册、登录；可浏览产品介绍页 |
| 用户 | 已注册登录 | 视频创作、画布创作、资产管理、积分/套餐查看与充值、历史记录、下载 |
| 管理员 | 后台账号 | 渠道/模型/价格/套餐管理、用户与积分管理、任务监控、系统设置 |

## 3. 功能边界（P0）

### 3.1 保留并改造（用户端）

1. **视频创作台**
   - 提示词 + 最多 7 张参考图（上传/拖拽/粘贴/从资产选择）。
   - 参数：模型、时长、比例、分辨率、生成声音、水印、参考模式（首尾帧 / 参考图）。
   - 提交后进入异步任务：排队中/生成中/成功/失败，显示进度与耗时；失败展示原因并可重试。
   - 结果：在线播放、下载 MP4、保存到「我的资产」、作为新任务参考。
   - 历史记录（服务端，跨设备），支持预览参数、继续生成、删除。
2. **无限画布**
   - 多画布项目；项目云同步（登录账号下跨设备）；保留导入/导出（ZIP，内含 `projects.json` 与媒体文件）。
   - 节点：图片（上传/资产插入）、视频（上传/生成）、文本（提示词）、分组、生成配置节点（视频模式）。
   - 节点连线、拖拽缩放、框选、多选、撤销重做、小地图、三种背景、浅/深主题、快捷键。
   - 画布内视频生成：生成配置节点汇总上游文本与图片 → 提交视频任务 → 轮询 → 生成视频节点；刷新后可恢复未完成任务。
   - 节点保存到资产、下载、裁剪/首尾帧截取（仅作为参考图，不生成图片）。
3. **我的资产**
   - 服务端素材库：视频、图片、文本；上传、编辑标题/封面/标签/备注、搜索、类型筛选、分页、下载、删除。
   - 资产可插入画布或作为视频参考图。
4. **账户**
   - 注册（邮箱 + 密码，MVP 不做邮箱验证码）、登录、退出、修改密码。
   - 积分余额、积分流水（充值/赠送/消费/退款）、套餐信息。
   - MVP 充值方式：管理员后台手工充值 + 兑换码兑换；在线支付列为 P1。
   - 偏好设置：主题、节点生成行为、自动聚焦等（合并原 `/config` 的偏好项，存放账户页）。

### 3.2 新增（平台能力）

5. **管理后台**
   - 管理员登录（独立入口/账号）。
   - 渠道管理：名称、Base URL、API Key（加密存储、脱敏展示）、协议档位（`openai-official` / `newapi` 为 P0，`json-envelope` / `dual-dialect` 预留 P1）、启停、连通性测试。
   - 模型管理：渠道、上游模型名、展示名、能力（固定 video）、上架状态、参数限制（时长/尺寸/分辨率/参考图数量）、积分定价、排序。
   - 用户管理：列表、搜索、禁用/启用、积分调整、套餐开通、明细查看。
   - 套餐/积分包管理：名称、价格、积分额度、有效期、上下架。
   - 任务监控：全平台任务列表、状态、耗时、模型、用户、扣费、错误信息、失败重试。
   - 兑换码管理：批量生成、列表、作废、导出。
   - 系统设置：注册赠送积分、充值比例、每用户并发上限、任务超时、文件保留策略、注册开关、顶部公告。
   - 运营审计（P1）：管理员登录、调账、渠道/模型变更记录。
6. **账号与计费服务**
   - JWT 鉴权；密码 BCrypt；管理员与用户分表或角色区分。
   - 积分账户 + 不可变流水账；任务创建预扣、成功结算、失败/取消全额退回。
   - 兑换码、手工充值。
7. **模型网关（OpenAI 兼容视频协议）**
   - 后端统一对接上游 `POST /v1/videos`（multipart）、`GET /v1/videos/{id}`、`GET /v1/videos/{id}/content`。
   - 异步任务表 + 后台轮询 worker；结果文件下载落盘，前端只访问平台域名。
   - 上游差异（路径、信封、状态文案、结果字段）在渠道/模型层适配，前端不感知。

## 4. 核心流程

1. **注册 → 登录 → 获得赠送积分**
2. **创作**：创作台/画布选择模型 → 填提示词/参考图/参数 → 平台校验积分并预扣 → 创建任务 → 后端调上游 `/v1/videos` → 轮询 → 下载视频落盘 → 任务成功结算（失败退款）→ 前端播放/下载/存资产
3. **资产**：上传/保存生成结果 → 资产库管理 → 插入画布或作为参考图
4. **管理**：管理员配置渠道与模型 → 定价 → 用户充值/兑换 → 任务监控与异常处理

## 6. 计费规则草案（待定价）

- 充值比例：`1 元 = 100 积分`（后台可改）。
- 模型定价：`单价（积分/秒，480p 基准）× 分辨率系数 × 时长（秒）`，可选 `音频系数`；分辨率系数如 480p=1.0、720p=1.5、1080p=2.0（模型级配置）。
- 新用户注册赠送积分：默认 100（后台可改）。
- 任务失败/取消全额退回；成功后按实际参数结算。
- 积分流水记录：类型（充值/赠送/消费/退款/调整）、数量、余额快照、关联任务/订单、操作人、时间。
- 套餐：名称、价格、积分额度、有效期（天）、上架状态；购买/开通后写入流水；套餐内积分可设过期时间（P1）。

## 8. 风险与依赖

- **上游协议差异**：不同聚合站路径/信封/状态字段不一致，需渠道级适配；必须有可用测试账号（Base URL + Key + 模型）才能联调。
- **支付渠道**：在线支付依赖商户资质，MVP 先手工/兑换码。
- **画布媒体服务端化**：参考项目全部媒体存 localforage，改造为服务端存储是最大工程量，需分阶段（先新链路，再清理旧代码）。
- **前端裁剪耦合**：画布页面约 198KB，图片生成/助手/插件/音频与画布深度耦合，需按「先删路由 → 再删功能入口 → 最后清代码」顺序推进，避免一次性大爆炸。
- **无现成测试**：参考项目测试很少，后端需补关键链路测试，前端至少保证 `typecheck` + 构建通过。
